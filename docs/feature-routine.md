# Навык «Рутина»

Рабочее название: **routine**. Два режима:
- **Рутина чата** — публикуется в выбранный чат, настраивает админ.
- **Моя Рутина** — публикуется в ЛС бота, настраивает любой юзер для себя.

## 1. Суть

Бот по расписанию присылает свежую подборку из сети по запросу юзера. Запрос — свободный текст («новости про ИИ», «события в Москве», «крипторынок BTC/ETH»). Источники бот ищет сам через web-search, RSS/X/Reddit/сайты вручную добавлять не нужно.

В отличие от ленты соцсетей — **разовые публикации по расписанию**, не поток. Каждый выпуск собирается прямо в момент отправки, не кэшируется.

## 2. Как работает

- **Wizard в ЛС бота**: запрос → периодичность → время+TZ → превью → сохранение → (для чата — выбор чата).
- **LLM-движок**: OpenRouter, модель `perplexity/sonar-pro` (web-search-native). Системный промпт — `src/data/routinePrompt.md`:
  - до 4 буллетов, по одному факту/событию на буллет
  - каждый буллет заканчивается markdown-ссылкой `[Источник](URL)`
  - язык запроса (default — русский)
  - без вступлений/заключений
- **Превью** генерится реальным запросом, не mock — юзер видит, как будет выглядеть выпуск.
- **Правки промпта** — до 3 итераций превью на черновик.
- **Публикация по расписанию**: каждые N дней в заданное время в заданном TZ. Для чата — `pushGroupMessage`, для ЛС — `pushBot`.

## 3. Параметры

- **`prompt`** — свободный текст запроса, до 500 символов.
- **`intervalDays`** — периодичность: 1 / 3 / 7.
- **`time`** — время публикации в формате `HH:MM`.
- **`tz`** — часовой пояс строкой (`МСК`, `GMT+3` и т.п.), default `МСК`.
- **`target`** — `chatId` (рутина чата) или `__me__` (Моя Рутина).
- **`topN`** — хардкод 5, модель режет до 4.
- **`active`** — toggle pause/resume.
- **`edits`** — счётчик правок промпта в превью, лимит 3.
- **`template`** — `crypto` / `dev` / `news` / `custom` (custom для wizard'а).

Лимиты тарифа:
- **Free**: 1 рутина, ежедневное расписание, до 2 источников (для legacy template-режима).
- **Pro**: до 5 рутин, любое расписание, до 5 источников.

## 4. Флоу юзера (с текстами сообщений)

### Шаг 1 — старт wizard

Точки входа:
- **Рутина чата**: deep-link из настроек фичи в мини-аппе (`?startRoutineFor=<chatId>`) или кнопка «🔁 Создать рутину в боте» на странице настроек чата.
- **Моя Рутина** (две точки):
  - Кнопка «🔁 Создать Мою Рутину» в персональном онбординге (`onboard-user-show-routine`).
  - Кнопка «🔁 Мои Рутины» в персональных навыках (`user-settings`) → экран `personal-routine-info` → «🔁 Создать Мою Рутину» (если ещё ни одной) или «🔁 Создать ещё одну» (если уже есть).

### Шаг 2 — выбор чата (только для рутины чата)

Picker чатов, где юзер админ. Для Моей Рутины шаг пропускается — сразу к запросу.

### Шаг 3 — запрос

Бот:
> 🔁 Новая рутина
>
> Опиши своими словами, что присылать [в чат / тебе в ЛС]. Бот находит это в сети и регулярно публикует со ссылками на источники.
>
> Например:
> • «свежие новости про ИИ и LLM»
> • «главные события крипторынка: BTC, ETH»
> • «интересные события в Москве»
> • «новые статьи на тему психологии»

Юзер: вводит произвольный текст (max 500 символов).

### Шаг 4 — периодичность

Бот:
> ✏️ Запрос принят:
> «новости про ИИ»
>
> Как часто публиковать?
>
> [🔁 Раз в день] [🔁 Раз в 3 дня] [🔁 Раз в неделю]

### Шаг 5 — время + TZ

Бот:
> ⏰ Когда публиковать? Напиши время и часовой пояс (например 09:00 МСК или 18:30 GMT+3).
>
> ⚠️ Данные собираются в сети на момент выпуска — каждый раз свежие.

Юзер: вводит время+TZ одной строкой. Парсер — regex `^(\d{1,2})(?::(\d{2}))?\s*(.*)$`:
- часы 0–23, минуты 0–59 (default 00)
- TZ — любой суффикс, default `МСК`

### Шаг 6 — превью

Бот тянет `fetchRoutineDigest` (server fn, OpenRouter):
> 🔎 Собираю данные на текущую дату и время…

Потом:
> 👀 Сейчас покажу, как это будет выглядеть [в чате / в ЛС]:
>
> ━━━━━━━━━
> 📰 новости про ИИ
>
> • OpenAI выпустила GPT-5.2 с контекстом до 5M токенов. [Источник](url)
> • Anthropic анонсировала Opus 5 на Q3. [Источник](url)
> • Google DeepMind показал Gemini 3 Ultra. [Источник](url)
> ━━━━━━━━━
>
> Сохранить рутину?
>
> ✏️ Правок осталось: 3
>
> [💾 Сохранить] [✏️ Изменить запрос] [🗑 Удалить]

При ошибке fetch:
> ⚠️ Не удалось получить данные: <error>.
>
> Попробуй ещё раз позже.

### Шаг 7 — сохранение

Для рутины чата:
> ✅ Рутина создана для «Курьеры Москва»!
>
> Будет выходить раз в день в 09:00 МСК, данные собираются в сети на момент каждого выпуска.
>
> [📤 Отправить в чат сейчас] [⚙️ Открыть настройки]

Для Моей Рутины:
> ✅ Моя Рутина создана!
>
> Будет приходить раз в день в 09:00 МСК прямо сюда, в ЛС. Данные собираются в сети на момент каждого выпуска.
>
> [📤 Прислать выпуск сейчас] [⚙️ Настроить мои рутины]

### Шаг 8 — публикация выпуска

В чате (`pushGroupMessage`):
```
📰 новости про ИИ

• OpenAI выпустила GPT-5.2 с контекстом до 5M токенов. [Источник]
• Anthropic анонсировала Opus 5 на Q3. [Источник]
• Google DeepMind показал Gemini 3 Ultra. [Источник]

⚙️ Рутина · раз в день в 09:00 МСК · /routines
```

В ЛС (`pushBot`):
```
📰 новости про ИИ

• …
• …

⚙️ Моя Рутина · раз в день в 09:00 МСК · /routines
```

## 5. Мини апп

### Карточка в каталоге
`feature: routine` в `_tabs.marketplace.tsx`. Bullet-list:
- 🔎 Свежие новости и статьи — бот находит по теме в интернете
- 📅 По расписанию — раз в день, 3 дня или неделю
- 🧩 Настройка за минуту — опиши тему своими словами в ЛС
- 📡 Доп. источники — RSS и сайты сверх поиска по сети

Тариф: «Бесплатно». `NEW`-бейдж.

### Страница настроек фичи на чате
`/chat/$chatId/feature/routine` → `RoutineSettings`:
- Блок «Как работает» — короткое описание + лимиты тарифа.
- Список рутин: имя, расписание (`Ежедневно в 09:00`), счётчик `N из 5`, чипы источников, `lastRunAt`, toggle pause/resume.
- Кнопки на каждой: «Изменить» (запускает wizard через `?startRoutineFor`) / «Удалить».
- Кнопка «+ Создать рутину в боте» — переключает в private режим, открывает wizard.

### Личный раздел в ЛС бота
Меню «✨ Персональные навыки» (`user-settings`) показывает строку:

> 🔁 Мои Рутины: N рутин (или «не создано»)

Кнопка «🔁 Мои Рутины» открывает `personal-routine-info`:
- Если ни одной — короткое описание + кнопка «🔁 Создать Мою Рутину».
- Если есть — список с именем, статусом (активна / на паузе) и расписанием, кнопки «🔁 Создать ещё одну» / «⚙️ Открыть Mini App».

Persist: рутины пишутся в `routinesByChat["__me__"]` (через тот же `addRoutine`), живут между шагами сессии.

### Личный раздел в мини-аппе (план)
Отдельная вкладка «Мои рутины» в `/me` с тем же UI, что `RoutineSettings` для чата, без picker'а. Сейчас не реализована — управление только через ЛС бота + переход в Mini App.

## 6. Edge cases

- **`fetchRoutineDigest` упал** → сообщение об ошибке, draft остаётся, юзер может перезапустить.
- **Правки кончились** (3 raunds) → кнопка «Изменить запрос» исчезает, остаются только «Сохранить» / «Удалить».
- **Битый формат времени** → бот переспрашивает: «Нужно время в формате ЧЧ:ММ и пояс — например 09:00 МСК».
- **Длинный запрос** → обрезается до 500 символов.
- **Длинное имя** → имя рутины = первые 40 символов промпта.
- **Бот выкинут из чата** → рутины этого чата pause (план, не в текущем prototype).
- **Источники в legacy template** (crypto/dev/news) — preset chips в UI, при custom-wizard'е список пустой.

## 7. Метрики

- **`routine_wizard_started`** — юзер начал wizard. Свойства: `source` (`chat_settings` / `bot_button` / `onboarding` / `user_settings`), `target` (`chat` / `personal`).
- **`routine_prompt_submitted`** — ввёл текст запроса. Свойства: `prompt_len`, `target`.
- **`routine_interval_chosen`** — тапнул кнопку периодичности. Свойства: `interval_days`, `target`.
- **`routine_time_submitted`** — ввёл время+TZ. Свойства: `time`, `tz`, `target`.
- **`routine_preview_generated`** — `fetchRoutineDigest` вернул успех. Свойства: `target`, `latency_ms`, `digest_chars`.
- **`routine_preview_failed`** — `fetchRoutineDigest` упал. Свойства: `target`, `error`.
- **`routine_preview_edited`** — тап «Изменить запрос». Свойства: `target`, `edits_count`.
- **`routine_saved`** — рутина создана. Свойства: `target`, `chat_id?`, `interval_days`, `time`, `tz`.
- **`routine_discarded`** — удалил черновик до сохранения. Свойства: `target`, `stage`.
- **`routine_published`** — шедулер опубликовал выпуск. Свойства: `routine_id`, `target`, `chat_id?`, `bullets_count`, `latency_ms`.
- **`routine_published_manual`** — тап «Отправить в чат сейчас» / «Прислать выпуск сейчас». Свойства: `routine_id`, `target`, `chat_id?`.
- **`routine_paused`** / **`routine_resumed`** — toggle в настройках. Свойства: `routine_id`, `target`.
- **`routine_deleted`** — рутина удалена. Свойства: `routine_id`, `target`, `age_days`.

Воронка: `wizard_started` → `prompt_submitted` → `interval_chosen` → `time_submitted` → `preview_generated` → `saved` → `published` (D1/D7/D30 retention).

## 8. Связанные файлы

- `src/lib/routineFetch.ts` — server fn, OpenRouter call.
- `src/data/routinePrompt.md` — системный промпт.
- `src/data/chats.ts` — типы `Routine`, `RoutineSchedule`, `RoutineSource`, `ROUTINE_TEMPLATES`.
- `src/store/chats.ts` — `routinesByChat`, `addRoutine`, `updateRoutine`, `deleteRoutine`.
- `src/routes/index.tsx` — wizard logic (`beginRoutinePrompt`, `previewRoutine`, `saveRoutine`, `sendRoutineToChat`), онбординг кейсы `onboard-user-show-routine` / `onboard-user-routine-start`.
- `src/components/FeatureSettings.tsx` — `RoutineSettings` (страница настроек на чате).
- `src/routes/_tabs.marketplace.tsx` — карточка `routine` в каталоге.

## 9. Roadmap

- Вкладка «Мои рутины» в `/me` с тем же списком/toggle/edit/delete, что `RoutineSettings` для чата.
- Audience-фильтр карточки `routine` в каталоге: показывать в личных тоже.
- Шедулер на стороне сервера (сейчас — только демо-отправка по кнопке).
- Фидбэк-кнопки 👍/👎 под постом + автопауза мёртвых рутин.
- AI-курирование («следи за всё что выходит про Tesla»).
- Trigger-based рутины («если BTC упал >5% за день — публикуй экстренный пост»).
- Гибрид: рутина + сегодняшнее саммари чата = «утренний выпуск».
